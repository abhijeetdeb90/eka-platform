# Trust and Verification Framework

## Trust is multi-dimensional

Trust should not be reduced to a single universal score.

Dimensions:

- Source quality
- Attribution
- Context completeness
- Review status
- Community feedback
- Conflict/dispute status
- Creator history
- Editorial review

## Suggested labels

- Source provided
- Community context added
- Editorially reviewed
- Under review
- Disputed context
- Sponsored/promotional
- User experience/opinion

## Verification workflow

Submission → Automated completeness checks → Human review where required → Publish or request changes → Post-publication monitoring → Corrections/versioning.

## Sensitive categories

Religious claims, health-related rituals, financial claims, legal claims, allegations, and identity-related content require stronger review and careful wording.

## Prohibited shortcut

AI-generated confidence must not be presented as proof of cultural, religious, historical, or factual authenticity.
