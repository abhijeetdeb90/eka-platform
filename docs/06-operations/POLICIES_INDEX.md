# Content Rights and Media Policy

## Before publishing media

Record:

- Source URL or reference
- Creator/owner
- License or permission basis
- Attribution requirement
- Usage scope
- Expiration/revocation condition
- Takedown contact/process

## User submissions

Terms should address:

- User's rights and responsibility
- License granted to EKA
- Moderation and removal
- Complaints and takedowns
- Privacy and personal data
- Commercial disclosures

## Rule

Do not assume that publicly visible content is free to copy, modify, or commercially reuse.
