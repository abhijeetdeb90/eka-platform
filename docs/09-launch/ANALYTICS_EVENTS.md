# Analytics and Experimentation

## North-star behavior

Repeated meaningful discovery and learning, followed by saving, discussion, contribution, or return visits.

## Event groups

- Signup completed
- Interest selected
- Content viewed
- Source opened
- Content saved
- Creator followed
- Comment added
- Report submitted
- Contribution submitted
- Search performed
- Review completed
- Return session

## Rules

- Collect only necessary data.
- Document event definitions.
- Avoid dark patterns.
- Separate product analytics from audit logs.
- Provide consent and privacy controls where required.
- Define success metrics before experiments.
